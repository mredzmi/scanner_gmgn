# GMGN AI Scanner

Mobile-friendly Solana token scanner MVP.

## Current MVP
- Paste Solana contract address
- Fetches live pair/market data from DexScreener
- Calculates a rule-based 0–100 screening score
- Shows liquidity, volume, buy/sell pressure and momentum
- Flags basic market risks

## Important
This MVP is a screening tool, not financial advice. Smart-money, holder concentration, dev-wallet and rug detection are planned for the next version.
